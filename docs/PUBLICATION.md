# 공개 범위

공개: CPU 실행기·변환·증류·평가 스크립트, 직접 작성한 작은 KO/EN 문장 목록, 비식별화한 1~3차 작업 기록과 선택 모델 metadata, 프로파일을 제외한 작은 결과 JSON, 라이선스.

제외: 개인키·토큰·인증 설정·환경 파일, 서버 주소/계정과 개인 작업 경로, 가상환경, 원본/학생 모델 가중치, checkpoint, 대용량 합성 데이터, WAV, 배포 tar, 다운로드한 타사 번들, profiler dump, 빌드 산출물과 전체 로그. `.gitignore`와 커밋 파일 검사로 제외한다. 로컬 원본은 삭제하지 않는다.

과거 문서의 절대 사용자 경로·접속 정보는 `<WORKSPACE>`, `<USER_HOME>`, `<REMOTE_WORKSPACE>`, `<SSH_USER>`, `<SSH_HOST>`, `<SSH_KEY_FILE>`로 치환했다. 치환된 접속 예시는 실행할 수 없다. 역사 문서의 로컬 모델/음성/로그 경로는 실험 식별을 위해 보존했지만 해당 자산은 Git에 없다. 학습 가중치의 공개 다운로드를 제공하는 저장소가 아니다.

과거 `source_index.json`과 집계 내부 SHA-256은 실험 당시 원시 파일의 해시다. 비식별화된 공개 파일과 다를 수 있다. [public_source_index.json](../records/public_source_index.json)은 공개한 결과 JSON에 대해 다시 계산한 해시다. 측정 숫자를 편집해 개선된 것으로 보이게 하지 않는다. `model_inventory.json`은 초기 시점 목록이며 현재 선택 모델 목록은 `docs/models/`를 따른다.

`tools/audit_publication.py`는 Git index의 공개 파일을 검사한다. 실제 비밀키를 열지 않고 파일명·대형/바이너리 자산·비밀정보 패턴·개인 경로·공개 IP 유출을 점검한다. 외부 서비스를 사용하거나 검사 대상 내용을 외부로 전송하지 않는다.

공개 준비 검증: 전체 Python 소스 컴파일과 정적 검사 통과, 커밋 대상 민감정보·바이너리·크기 검사 통과, 공개 결과 JSON 해시 검증 통과. 선택 모델의 로컬 최소 실행 패키지는 별도 생성하고 구성과 가이던스 설명을 검사했다. 이 파일은 Git에 넣지 않았다. 원본 core와의 추론 일치 검사는 기존 통과 기록을 보존했다.
