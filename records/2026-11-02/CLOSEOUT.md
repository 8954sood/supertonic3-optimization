# 작업 종료·최종 공개 내보내기·디스크 정리

사용자가 현재 모델과 필요한 자료를 Hugging Face에 보관한 뒤 전체 작업을 정리하고 중단하도록 요청했다. 추가 최적화·학습·성능 측정 없이 보관과 정리만 수행했다.

## 보관 확인과 마지막 업로드

기존 모델 revision `f1d05bdb691d8769557e19644f3a63089992daf0`와 데이터 revision `e56d93c9959647c850b639a614e629e4e4ac1593`의 실제 공개 상태를 확인했다. F1200·E400·필수 원본50 체크포인트와 데이터는 이미 공개돼 있었다. 최종 Linux v5와 Mac 정규화 그래프는 공개 패키지에서 재생성하는 방식만 제공하고 직접 내보낸 파일은 아직 없었다.

정리 전에 다음 두 완전한 패키지를 모델 저장소에 추가했다.

- `models/F1200-retime-v5/`: 로컬 `models/F1200-retime-v5` 그대로. 22파일.
- `models/F1200-retime-arm64/`: 로컬 `models/round15-all-parts-row-norm` 그대로. 22파일.

새 고정 모델 revision은 **`cbef65027ca699895cdeb1acd3308eeeee2a7a63`**이다. 기존 파일 139개는 blob ID가 그대로임을 확인했다. 공통 LFS 3개는 서버에서 복사했고, 기존 파일 삭제는 하지 않았다. README와 asset manifest를 갱신하고 `releases/2026-11-02/final_exports_manifest.json`을 추가했다. 다운로드 도구에 최종 두 모델명을 추가하고 재현용 데이터 분류도 original50으로 지정했다. 데이터 revision은 변경하지 않았다.

추가한 두 모델은 F1200 학습 가중치·양자화·8스텝을 유지한 기존 export이며, 새로운 모델 학습이나 품질 변경이 아니다. runtime/native source는 기존 Git commit `d9340482a2626dfa3d9c04b684369082674aa8f3`의 코드로 준비한 것이다. 플랫폼별 빌드는 사용 기기에서 수행한다.

검증에는 인증 없는 공개 링크로 고유30개 객체 865,247,478 bytes를 내려받아 SHA-256을 계산했다. 필수 체크포인트 2개와 로컬 교사 데이터/metadata 770개도 공개 해시와 일치했다. 처음 Python HTTPS의 큰 파일 redirect 인증서 체인 검사에 실패해, 인증서 검사를 유지하는 macOS 기본 curl로 검증을 완료했다. 업로드 자격증명은 프로세스 메모리로만 전달하고 저장하지 않았다. [전체 검증 영수증](../../results/closeout_2026-11-02_hf_verification.json)

## 정리 범위와 기록

정리는 공개 백업 검증을 모두 마친 뒤 실행했다. 로컬의 가중치·학습 산출물·실험 데이터·생성 WAV·배포 중복 archive·native 바이너리·가상환경·프로젝트 캐시를 제거했다. `distill/` 안의 추적 중인 학습 소스와 corpus는 남겼다. 원격 서버에서는 이 작업 전용 폴더 안의 대용량 산출물만 제거했다. SSH 접속키, Git 추적 소스/기록, 전역 캐시 및 서버의 다른 작업은 유지했다.

공개되지 않은 작은 실험 소스·metadata·로그는 정리 전에 비공개 archive로 모았다. 로컬 archive는1996개 메모, 서버 archive는2531개 메모이다. 합계 약93MB이며 Git/HF에는 업로드하지 않았다. archive 경로 안전성과 내부 hardlink 대상 및 알려진 자격증명 패턴 부재를 확인했다. 공개된 필수 모델·학습 재현 자료의 복원에는 이 비공개 메모가 필요하지 않다.

| 범위 | 제거한 논리 파일 용량 | 관측된 여유 공간 증가 |
| --- | ---: | ---: |
| 로컬 프로젝트 | 15,116,490,881 bytes | 12,008,103,936 bytes |
| 검증 서버 작업 폴더 | 9,473,766,267 bytes | 7,707,914,240 bytes |

파일의 논리 용량, hardlink/공유 블록과 실제 여유 공간 증가는 다르다. 전체 삭제 경로·파일 수·보존 archive의 해시는 [로컬 영수증](../../results/closeout_2026-11-02_local_cleanup.json), [서버 영수증](../../results/closeout_2026-11-02_server_cleanup.json)에 있다.

## 종료 상태

작업은 사용자의 요청에 따라 종료했다. 로컬 청취 서버 포트7788/57727과 작업용 추론·실험 프로세스는 실행 중이지 않으며 추가 실행을 예약하지 않았다. 모델/데이터는 공개 고정 revision에서 받을 수 있고 소스·성능·실패 이력은 Git에 남아 있다. 복원을 위한 최소 명령은 [최종 상태 안내](../../docs/FINAL_STATE.md)를 따른다. 18차의 저사양 공유 서버 성능 한계는 그대로 유지한다.
